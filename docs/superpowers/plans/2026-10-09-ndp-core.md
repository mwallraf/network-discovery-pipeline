# ndp core tool (plan 1 of 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `ndp` command-line tool that scans the discovery prefixes with nmap, turns the XML into a device inventory, and publishes JSON, legacy-compatible CSV, a services CSV, a run manifest and a README, packaged as a container image.

**Architecture:** A small Python package (`src/ndp/`) with one module per responsibility: config, input files, nmap XML reading, device building, inventory (merge + mgmt IP), file helpers, writers, manifest, and one module per step (`scan`, `parse`, `publish`, `run`). Steps talk to each other only through files: the scan XML, `devices-<date>.json`, and per-step result files in `<output>/state/`. The CLI is a thin wrapper that loads config, runs a step, saves its result and prints it as JSON.

**Tech Stack:** Python ≥ 3.11, pydantic 2 (config validation), PyYAML, stdlib `xml.etree`, `csv`, `argparse`; pytest; Docker (built `FROM` the scanner image); GitHub Actions → GHCR.

**Spec:** `docs/superpowers/specs/2026-10-09-network-discovery-pipeline-design.md`

**Plans:** this is plan 1 of 3. Plan 2 = `ndp exclude` (pass 1; its rules are still open in spec section 7). Plan 3 = private site config repo, server wrapper, n8n workflow, parallel rollout. Until plan 2 exists, `ndp scan` uses `<inputs>/exclude.txt` when present and otherwise scans without exclusions and warns.

## Global Constraints

- Python `>=3.11`. Runtime dependencies only `pydantic>=2.6,<3` and `PyYAML>=6.0`; dev dependency `pytest>=8`.
- Public repo: no real prefixes, hostnames, community strings, paths or customer data anywhere (code, tests, docs). Use `192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24` and invented names.
- Secrets: SNMP communities only from env `SNMP_COMMUNITIES` (comma-separated). Never in command-line arguments, logs, the run manifest, state files or outputs other than the legacy CSV `communities` column (which `outputs.legacy_csv_communities: false` blanks).
- Every step prints a JSON summary on stdout and logs on stderr. Exit codes: `0` success, `2` success with warnings, `1` failure.
- `*-latest*` symlinks are replaced atomically and only after the dated file is complete. A failed step never moves a `*-latest*` link.
- Legacy CSV columns, exactly and in order: `_key,_updates,hostname,status,telnet,ssh,snmp,bgp,enterprise,os_slug,function,mgmt_ip,mgmt_safe,sysObjectId,sysContact,sysLocation,sysUpTime,physSerial,physSoftware,physDescription,physName,physModel,ip,communities`.
- Summary CSV columns: `id,started,started_str,endtime,endtime_str,elapsed,hosts_total,hosts_up,hosts_down,filename` (`id` is always `1`, as the legacy parser wrote).
- File names (local time): `<output>/nmap/scan-YYYYMMDDTHHMMSS.xml|.txt`, `<output>/nmap/scan-latest.xml|.txt`, `<output>/devices-YYYYMMDD.json`, `devices-latest.json`, `discovery.csv.YYYYMMDD`, `discovery-latest.csv`, `discovery-summary.csv`, `services-YYYYMMDD.csv`, `services-latest.csv`, `run-YYYYMMDDTHHMMSS.json`, `README.md`, `<output>/state/last-<step>.json`.
- Deviations from the spec's example config, deliberate: `outputs.json` is named `outputs.devices_json` (a field called `json` clashes with pydantic), `scanner.nmap_path` is added (default `nmap`), `scanner.docker_network` is left out (the server wrapper owns it, plan 3).

## Review Focus

- **Interrupted nmap run (truncated XML):** `parse_scan` raises a clear "interrupted scan?" error; `scan`/`parse` fail with exit 1 and no `*-latest*` link moves. Tests in Task 4 and Task 9.
- **Scan finds zero devices up:** `parse` fails instead of writing an empty inventory that `publish` would turn into an empty `discovery-latest.csv`. Test in Task 8.
- **IPv6 prefix coming from Nautobot:** skipped with a warning and never handed to nmap. Tests in Task 3 and Task 9.
- **Nested prefixes with different roles** (e.g. a /24 inside a /16): an IP gets the role of the most specific prefix. Test in Task 6.
- **Pipeline paused longer than `keep_days`:** housekeeping never deletes a file a `*-latest*` link points to. Test in Task 7.

`src/ndp/result.py`:

```python
"""The result every step returns, prints and saves."""

from __future__ import annotations

import json
from dataclasses import dataclass, field
from datetime import datetime

EXIT_CODES = {"ok": 0, "warning": 2, "failed": 1}


def now_local() -> datetime:
    """Current local time, timezone-aware (file names use local time)."""
    return datetime.now().astimezone()


@dataclass
class StepResult:
    step: str
    error: str | None = None
    warnings: list[str] = field(default_factory=list)
    counts: dict[str, int] = field(default_factory=dict)
    outputs: dict[str, str] = field(default_factory=dict)
    started: str = ""
    finished: str = ""

    @property
    def status(self) -> str:
        if self.error:
            return "failed"
        return "warning" if self.warnings else "ok"

    @property
    def exit_code(self) -> int:
        return EXIT_CODES[self.status]

    def to_dict(self) -> dict:
        return {
            "step": self.step,
            "status": self.status,
            "error": self.error,
            "warnings": list(self.warnings),
            "counts": dict(self.counts),
            "outputs": dict(self.outputs),
            "started": self.started,
            "finished": self.finished,
        }

    def to_json(self) -> str:
        return json.dumps(self.to_dict(), indent=2)
```

`src/ndp/cli.py`:

```python
"""Command line entry point: ndp [-c CONFIG] STEP."""

from __future__ import annotations

import argparse
import logging
import os
import sys

from ndp import __version__
from ndp.result import StepResult

DEFAULT_CONFIG = "/etc/ndp/ndp.yaml"


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(
        prog="ndp",
        description="Network discovery pipeline: scan, parse and publish an SNMP device inventory.",
    )
    parser.add_argument("--version", action="version", version=f"ndp {__version__}")
    parser.add_argument(
        "-c",
        "--config",
        default=os.environ.get("NDP_CONFIG", DEFAULT_CONFIG),
        help="path to ndp.yaml (default: $NDP_CONFIG or /etc/ndp/ndp.yaml)",
    )
    sub = parser.add_subparsers(dest="command", required=True, metavar="STEP")
    _add_commands(sub)
    return parser


def _add_commands(sub) -> None:
    """Register one subcommand per step (added by later tasks)."""


def emit(result: StepResult) -> int:
    """Print the step result as JSON on stdout and return its exit code."""
    print(result.to_json())
    return result.exit_code


def main(argv: list[str] | None = None) -> int:
    logging.basicConfig(level=logging.INFO, stream=sys.stderr, format="%(levelname)s %(message)s")
    args = build_parser().parse_args(argv)
    return args.handler(args)
```

```python
"""ndp.yaml: static rules, versioned in git. Secrets come from the environment."""

from __future__ import annotations

import os
from collections.abc import Mapping
from pathlib import Path
from typing import Annotated

import yaml
from pydantic import BaseModel, ConfigDict, Field, ValidationError, field_validator

Port = Annotated[int, Field(ge=1, le=65535)]


class ConfigError(Exception):
    """The configuration is missing or invalid."""


class _Model(BaseModel):
    model_config = ConfigDict(extra="forbid")


class Paths(_Model):
    output: Path
    inputs: Path


class PrefixRole(_Model):
    function: str = ""
    note: str = ""


class Nautobot(_Model):
    device_roles: list[str] = Field(default_factory=list)
    # dict order is the management IP preference
    prefix_roles: dict[str, PrefixRole] = Field(min_length=1)

    @field_validator("prefix_roles", mode="before")
    @classmethod
    def _allow_bare_role(cls, value):
        # "ROLE:" without a mapping loads as None in YAML
        if isinstance(value, dict):
            return {key: ({} if val is None else val) for key, val in value.items()}
        return value


class Scanner(_Model):
    nmap_path: str = "nmap"
    snmp_timeout_ms: int = Field(default=4000, gt=0)
    timing: int = Field(default=4, ge=0, le=5)
    tcp_ports: list[Port] = Field(default_factory=lambda: [22, 23, 179], min_length=1)
    host_discovery_ports: list[Port] = Field(default_factory=lambda: [22, 23], min_length=1)


class Outputs(_Model):
    devices_json: bool = True
    legacy_csv: bool = True
    legacy_csv_communities: bool = True
    services_csv: bool = True


class Housekeeping(_Model):
    keep_days: int = Field(default=30, ge=1)
    owner: int | str | None = None
    group: int | str | None = None
    file_mode: str = "0664"
    dir_mode: str = "0775"

    @field_validator("file_mode", "dir_mode")
    @classmethod
    def _octal(cls, value: str) -> str:
        try:
            mode = int(value, 8)
        except ValueError:
            raise ValueError(f"not an octal mode: {value!r}") from None
        if not 0 <= mode <= 0o7777:
            raise ValueError(f"mode out of range: {value!r}")
        return value


class Config(_Model):
    paths: Paths
    nautobot: Nautobot
    scanner: Scanner = Field(default_factory=Scanner)
    outputs: Outputs = Field(default_factory=Outputs)
    housekeeping: Housekeeping = Field(default_factory=Housekeeping)

    @property
    def scans_dir(self) -> Path:
        return self.paths.output / "nmap"

    @property
    def state_dir(self) -> Path:
        return self.paths.output / "state"


def load_config(path: Path) -> Config:
    path = Path(path)
    try:
        text = path.read_text()
    except OSError as exc:
        raise ConfigError(f"cannot read config {path}: {exc.strerror}") from None
    try:
        data = yaml.safe_load(text)
    except yaml.YAMLError as exc:
        raise ConfigError(f"invalid YAML in {path}: {exc}") from None
    if not isinstance(data, dict):
        raise ConfigError(f"{path}: the top level must be a mapping")
    try:
        return Config.model_validate(data)
    except ValidationError as exc:
        lines = [f"{'.'.join(str(part) for part in err['loc'])}: {err['msg']}" for err in exc.errors()]
        raise ConfigError(f"invalid config {path}:\n  " + "\n  ".join(lines)) from None


def communities_from_env(env: Mapping[str, str] | None = None) -> list[str]:
    env = os.environ if env is None else env
    communities = [c.strip() for c in env.get("SNMP_COMMUNITIES", "").split(",") if c.strip()]
    if not communities:
        raise ConfigError("SNMP_COMMUNITIES is not set or empty")
    return communities
```

```python
"""Input files generated before a run (by n8n from Nautobot, or by hand)."""

from __future__ import annotations

import ipaddress
import json
from dataclasses import dataclass, field
from pathlib import Path


class InputError(Exception):
    """An input file is missing or invalid."""


@dataclass(frozen=True)
class PrefixEntry:
    network: ipaddress.IPv4Network
    role: str


@dataclass
class PrefixInput:
    source: dict
    prefixes: list[PrefixEntry]
    warnings: list[str] = field(default_factory=list)


def _read_json(path: Path) -> dict:
    try:
        text = Path(path).read_text()
    except OSError as exc:
        raise InputError(f"cannot read {path}: {exc.strerror}") from None
    try:
        data = json.loads(text)
    except json.JSONDecodeError as exc:
        raise InputError(f"{path} is not valid JSON: {exc}") from None
    if not isinstance(data, dict):
        raise InputError(f"{path}: the top level must be an object")
    return data


def load_prefixes(path: Path) -> PrefixInput:
    data = _read_json(path)
    entries = data.get("prefixes")
    if not isinstance(entries, list):
        raise InputError(f"{path}: 'prefixes' must be a list")
    prefixes: list[PrefixEntry] = []
    seen: set[ipaddress.IPv4Network] = set()
    warnings: list[str] = []
    for index, entry in enumerate(entries):
        if not isinstance(entry, dict) or "prefix" not in entry or "role" not in entry:
            raise InputError(f"{path}: prefixes[{index}] needs 'prefix' and 'role'")
        try:
            network = ipaddress.ip_network(str(entry["prefix"]), strict=False)
        except ValueError:
            raise InputError(f"{path}: prefixes[{index}]: invalid prefix {entry['prefix']!r}") from None
        role = str(entry["role"])
        if network.version != 4:
            warnings.append(f"skipped IPv6 prefix {network} (role {role})")
            continue
        if network in seen:
            continue
        seen.add(network)
        prefixes.append(PrefixEntry(network, role))
    source = data.get("source") if isinstance(data.get("source"), dict) else {}
    return PrefixInput(source=source, prefixes=prefixes, warnings=warnings)
```

```python
"""Read an nmap XML report, including the SNMP NSE script results."""

from __future__ import annotations

import xml.etree.ElementTree as ET
from dataclasses import dataclass, field
from pathlib import Path

PORT_NAMES = {
    ("tcp", "22"): "ssh",
    ("tcp", "23"): "telnet",
    ("tcp", "179"): "bgp",
    ("udp", "161"): "snmp",
}


class NmapXmlError(Exception):
    """The scan file is missing, incomplete or not an nmap report."""


@dataclass
class ScanSummary:
    started: int
    started_str: str
    endtime: int
    endtime_str: str
    elapsed: str
    hosts_total: int
    hosts_up: int
    hosts_down: int
    filename: str


@dataclass
class Interface:
    name: str
    if_index: int | None = None
    if_alias: str = ""
    services: list[str] = field(default_factory=list)
    addresses: list[str] = field(default_factory=list)

    def to_dict(self) -> dict:
        return {
            "name": self.name,
            "ifIndex": self.if_index,
            "ifAlias": self.if_alias,
            "services": list(self.services),
            "addresses": list(self.addresses),
        }


@dataclass
class HostResult:
    ip: str
    status: str
    ports: dict[str, str] = field(default_factory=dict)
    communities: list[str] = field(default_factory=list)
    enterprise: str = ""
    sysdetails: dict[str, str] = field(default_factory=dict)
    interfaces: list[Interface] = field(default_factory=list)


@dataclass
class ScanReport:
    summary: ScanSummary
    hosts: list[HostResult]


def parse_scan(path: Path) -> ScanReport:
    path = Path(path)
    try:
        root = ET.parse(path).getroot()
    except FileNotFoundError:
        raise NmapXmlError(f"scan file not found: {path}") from None
    except ET.ParseError as exc:
        raise NmapXmlError(f"scan file {path} is not valid XML (interrupted scan?): {exc}") from None
    if root.tag != "nmaprun":
        raise NmapXmlError(f"{path} is not an nmap XML report")
    finished = root.find("runstats/finished")
    counts = root.find("runstats/hosts")
    if finished is None or counts is None:
        raise NmapXmlError(f"{path} has no run statistics (interrupted scan?)")
    summary = ScanSummary(
        started=int(root.get("start", "0")),
        started_str=root.get("startstr", ""),
        endtime=int(finished.get("time", "0")),
        endtime_str=finished.get("timestr", ""),
        elapsed=str(float(finished.get("elapsed", "0"))),
        hosts_total=int(counts.get("total", "0")),
        hosts_up=int(counts.get("up", "0")),
        hosts_down=int(counts.get("down", "0")),
        filename=str(path.resolve()),
    )
    hosts = [host for host in (_parse_host(el) for el in root.findall("host")) if host is not None]
    return ScanReport(summary=summary, hosts=hosts)


def _parse_host(el: ET.Element) -> HostResult | None:
    ip = next((a.get("addr") for a in el.findall("address") if a.get("addrtype") == "ipv4"), None)
    if ip is None:
        return None
    status_el = el.find("status")
    host = HostResult(ip=ip, status=status_el.get("state", "") if status_el is not None else "")
    for port in el.findall("ports/port"):
        name = PORT_NAMES.get((port.get("protocol"), port.get("portid")))
        state_el = port.find("state")
        if name and state_el is not None:
            host.ports[name] = state_el.get("state", "")
        for script in port.findall("script"):
            _apply_script(host, script.get("id", ""), _children(script))
    return host


def _children(el: ET.Element):
    """NSE structured output: keyed children -> dict, keyless children -> list."""
    keyed: dict = {}
    items: list = []
    for child in el:
        if child.tag == "elem":
            value = child.text or ""
        elif child.tag == "table":
            value = _children(child)
        else:
            continue
        key = child.get("key")
        if key is None:
            items.append(value)
        else:
            keyed[key] = value
    if keyed and items:
        keyed["_items"] = items
        return keyed
    return keyed if keyed else items


def _apply_script(host: HostResult, script_id: str, data) -> None:
    if script_id == "snmp-brute":
        for community in _valid_communities(data):
            if community not in host.communities:
                host.communities.append(community)
    elif script_id == "snmp-info" and isinstance(data, dict):
        host.enterprise = str(data.get("enterprise", ""))
    elif script_id == "snmp-sysdetails" and isinstance(data, dict):
        host.sysdetails = {key: val for key, val in data.items() if isinstance(val, str)}
    elif script_id == "snmp-ifalias-service" and isinstance(data, dict):
        # the old script version returned plain text only (no structured data)
        host.interfaces = [_interface(name, val) for name, val in data.items() if isinstance(val, dict)]


def _valid_communities(data) -> list[str]:
    found: list[str] = []
    if isinstance(data, dict):
        if "Valid credentials" in str(data.get("state", "")) and data.get("password"):
            found.append(str(data["password"]))
        values = list(data.values())
    elif isinstance(data, list):
        values = data
    else:
        return found
    for value in values:
        if isinstance(value, (dict, list)):
            found.extend(_valid_communities(value))
    return found


def _str_list(value) -> list[str]:
    return [item for item in value if isinstance(item, str)] if isinstance(value, list) else []


def _interface(name: str, data: dict) -> Interface:
    index = data.get("ifIndex")
    alias = data.get("ifAlias")
    return Interface(
        name=name,
        if_index=int(index) if isinstance(index, str) and index.isdigit() else None,
        if_alias=alias if isinstance(alias, str) else "",
        services=_str_list(data.get("services")),
        addresses=_str_list(data.get("addresses")),
    )
```

```python
"""One device record per scanned host, with the legacy normalization rules."""

from __future__ import annotations

import re
from dataclasses import dataclass, field

from ndp.nmapxml import HostResult, Interface

SNMP_FIELDS = (
    "sysObjectId", "sysContact", "sysLocation", "sysUpTime", "physSerial",
    "physSoftware", "physDescription", "physName", "physModel", "sysDescr",
)

_CISCO_VERSION = re.compile(r"^Cisco.*Version\s([\da-zA-Z\.\(\)]+),", re.MULTILINE | re.DOTALL)


def normalize_hostname(name: str) -> str:
    """Lowercase, domain stripped: 'PE-01.example.net' -> 'pe-01'."""
    return name.strip().split(".")[0].lower()


def normalize_port_state(state: str) -> str:
    """Any filtered state counts as closed (legacy rule)."""
    return "closed" if "filtered" in state else state


def detect_software(sysdescr: str, enterprise: str, phys_software: str) -> str:
    """Software version, falling back to sysDescr when ENTITY-MIB has none.

    - OneOS: the whole sysDescr is the software string.
    - Cisco: the 'Version x.y.z,' part of sysDescr.
    - Anything after ', ' is dropped (some Cisco devices report extra text).
    """
    software = phys_software
    if not software and len(sysdescr) >= 5:
        if sysdescr[:5].lower().startswith("oneos"):
            software = sysdescr
        if "cisco" in enterprise.lower():
            match = _CISCO_VERSION.match(sysdescr)
            if match:
                software = match.group(1)
    if ", " in software:
        software = software.split(", ")[0]
    return software


def detect_os_slug(enterprise: str, software: str, sysdescr: str) -> str:
    """OS flavor. Rules (same as the legacy parser):

    | enterprise contains | condition                             | slug          |
    |---------------------|---------------------------------------|---------------|
    | ciena               | software starts with saos-06/05/10    | saos6/5/10    |
    | ciena               | otherwise                             | ciena-generic |
    | oneaccess           | software (upper) contains -V5         | oneos5        |
    | oneaccess           | software contains -6                  | oneos6        |
    | oneaccess           | otherwise                             | oneos-generic |
    | cisco               | sysDescr (upper) contains IOS XR      | ios-xr        |
    | cisco               | sysDescr (upper) has CISCO IOS SOFTWARE | ios-xe      |
    | cisco               | otherwise                             | ios-generic   |
    """
    ent = enterprise.lower()
    slug = ""
    if "ciena" in ent:
        slug = "ciena-generic"
        if software.startswith("saos-06"):
            slug = "saos6"
        elif software.startswith("saos-05"):
            slug = "saos5"
        elif software.startswith("saos-10"):
            slug = "saos10"
    if "oneaccess" in ent:
        slug = "oneos-generic"
        if "-V5" in software.upper():
            slug = "oneos5"
        elif "-6" in software:
            slug = "oneos6"
    if "cisco" in ent:
        slug = "ios-generic"
        if "IOS XR" in sysdescr.upper():
            slug = "ios-xr"
        elif "CISCO IOS SOFTWARE" in sysdescr.upper():
            slug = "ios-xe"
    return slug


@dataclass
class Device:
    key: str
    hostname: str
    status: str
    ips: list[str]
    communities: list[str]
    ports: dict[str, str]
    enterprise: str
    os_slug: str
    snmp: dict[str, str]
    interfaces: list[Interface] = field(default_factory=list)
    updates: int = 0
    mgmt_ip: str = ""
    mgmt_safe: int = 0
    mgmt_role: str = ""
    function: str = ""

    def to_dict(self) -> dict:
        return {
            "key": self.key,
            "hostname": self.hostname,
            "status": self.status,
            "mgmt_ip": self.mgmt_ip,
            "mgmt_safe": self.mgmt_safe,
            "mgmt_role": self.mgmt_role,
            "function": self.function,
            "os_slug": self.os_slug,
            "updates": self.updates,
            "ips": list(self.ips),
            "communities": list(self.communities),
            "ports": dict(self.ports),
            "snmp": {**self.snmp, "enterprise": self.enterprise},
            "interfaces": [interface.to_dict() for interface in self.interfaces],
        }


def device_from_host(host: HostResult) -> Device:
    details = host.sysdetails
    snmp = {name: details.get(name, "") for name in SNMP_FIELDS}
    snmp["physSoftware"] = detect_software(snmp["sysDescr"], host.enterprise, snmp["physSoftware"])
    hostname = normalize_hostname(details.get("sysName", ""))
    communities = list(host.communities)
    if not communities and snmp["sysObjectId"]:
        # SNMP answered without a snmp-brute result: the default community worked
        communities = ["public"]
    return Device(
        key=hostname or snmp["physSerial"] or host.ip,
        hostname=hostname,
        status=host.status,
        ips=[host.ip],
        communities=communities,
        ports={name: normalize_port_state(state) for name, state in host.ports.items()},
        enterprise=host.enterprise,
        os_slug=detect_os_slug(host.enterprise, snmp["physSoftware"], snmp["sysDescr"]),
        snmp=snmp,
        interfaces=list(host.interfaces),
    )
```

```python
"""Merge hosts into devices and pick each device's management IP and function."""

from __future__ import annotations

import ipaddress
from dataclasses import dataclass

from ndp.config import PrefixRole
from ndp.devices import Device, device_from_host
from ndp.inputs import PrefixEntry
from ndp.nmapxml import HostResult

# taken from the most recent host instead of raising a conflict
ALWAYS_UPDATE = {"sysUpTime"}


@dataclass
class Inventory:
    devices: list[Device]
    warnings: list[str]


def build_inventory(
    hosts: list[HostResult],
    prefixes: list[PrefixEntry],
    prefix_roles: dict[str, PrefixRole],
) -> Inventory:
    warnings: list[str] = []
    by_key: dict[str, Device] = {}
    for host in hosts:
        if host.status != "up":
            continue
        device = device_from_host(host)
        existing = by_key.get(device.key)
        if existing is None:
            by_key[device.key] = device
        else:
            merge_device(existing, device, warnings)
    devices = sorted(by_key.values(), key=lambda d: d.key)
    for device in devices:
        assign_mgmt(device, prefixes, prefix_roles, warnings)
    return Inventory(devices=devices, warnings=warnings)


def _ip_key(ip: str) -> ipaddress.IPv4Address:
    return ipaddress.IPv4Address(ip)


def _merge_value(key: str, label: str, old: str, new: str, warnings: list[str]) -> str:
    if not new or old == new:
        return old
    if not old:
        return new
    warnings.append(f"{key}: conflicting {label} {old!r} vs {new!r} from another IP; kept the first")
    return old


def merge_device(existing: Device, new: Device, warnings: list[str]) -> None:
    existing.ips = sorted(set(existing.ips) | set(new.ips), key=_ip_key)
    existing.communities = sorted(set(existing.communities) | set(new.communities))
    for name, state in new.ports.items():
        old = existing.ports.get(name, "")
        if state and (not old or (old != state and old != "open")):
            existing.ports[name] = state
    for attr in ("status", "enterprise", "os_slug"):
        setattr(existing, attr, _merge_value(existing.key, attr, getattr(existing, attr), getattr(new, attr), warnings))
    for name, value in new.snmp.items():
        if name in ALWAYS_UPDATE:
            if value:
                existing.snmp[name] = value
        else:
            existing.snmp[name] = _merge_value(existing.key, name, existing.snmp.get(name, ""), value, warnings)
    known = {interface.name for interface in existing.interfaces}
    existing.interfaces.extend(i for i in new.interfaces if i.name not in known)
    existing.updates += 1


def role_for_ip(ip: str, prefixes: list[PrefixEntry]) -> str | None:
    """Role of the most specific prefix that contains the IP."""
    address = _ip_key(ip)
    best: PrefixEntry | None = None
    for entry in prefixes:
        if address in entry.network and (best is None or entry.network.prefixlen > best.network.prefixlen):
            best = entry
    return best.role if best else None


def assign_mgmt(
    device: Device,
    prefixes: list[PrefixEntry],
    prefix_roles: dict[str, PrefixRole],
    warnings: list[str],
) -> None:
    order = list(prefix_roles)
    ranked = []
    for ip in device.ips:
        role = role_for_ip(ip, prefixes)
        if role is not None:
            rank = order.index(role) if role in prefix_roles else len(order)
            ranked.append((rank, _ip_key(ip), role))
    if not ranked:
        device.mgmt_ip = min(device.ips, key=_ip_key)
        device.mgmt_role = ""
        device.function = ""
        device.mgmt_safe = 1 if len(device.ips) == 1 else 0
        warnings.append(f"{device.key}: no IP inside a known prefix, using {device.mgmt_ip}")
        return
    best = min(rank for rank, _, _ in ranked)
    candidates = sorted((item for item in ranked if item[0] == best), key=lambda item: item[1])
    _, address, role = candidates[0]
    device.mgmt_ip = str(address)
    device.mgmt_role = role
    device.function = prefix_roles[role].function if role in prefix_roles else ""
    device.mgmt_safe = 1 if len(candidates) == 1 else 0
```

```python
"""Safe file writes, latest links, permissions and retention."""

from __future__ import annotations

import grp
import os
import pwd
import tempfile
from datetime import datetime
from pathlib import Path

from ndp.config import Housekeeping

# dated files that housekeeping may delete, relative to the output folder
DATED_PATTERNS = (
    "nmap/scan-2*.xml",
    "nmap/scan-2*.txt",
    "discovery.csv.2*",
    "devices-2*.json",
    "services-2*.csv",
    "run-2*.json",
)


def write_text_atomic(path: Path, text: str) -> None:
    """Write to a temp file in the same folder, then rename over the target."""
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    fd, tmp = tempfile.mkstemp(dir=path.parent, prefix=f".{path.name}.", suffix=".tmp")
    try:
        with os.fdopen(fd, "w", newline="") as fh:
            fh.write(text)
        os.replace(tmp, path)
    except BaseException:
        Path(tmp).unlink(missing_ok=True)
        raise


def atomic_symlink(target_name: str, link: Path) -> None:
    """Point link at target_name (same folder) without a moment where it is missing."""
    link = Path(link)
    tmp = link.with_name(f".{link.name}.tmp")
    tmp.unlink(missing_ok=True)
    os.symlink(target_name, tmp)
    os.replace(tmp, link)


def _resolve_id(value: int | str | None, lookup, attr: str) -> int:
    if value is None:
        return -1
    if isinstance(value, int) or str(value).isdigit():
        return int(value)
    return getattr(lookup(str(value)), attr)


def apply_perms(path: Path, hk: Housekeeping) -> list[str]:
    """Apply mode and owner/group; problems become warnings."""
    path = Path(path)
    warnings: list[str] = []
    mode = int(hk.dir_mode if path.is_dir() else hk.file_mode, 8)
    try:
        os.chmod(path, mode)
    except OSError as exc:
        warnings.append(f"chmod {path}: {exc.strerror}")
    if hk.owner is None and hk.group is None:
        return warnings
    try:
        uid = _resolve_id(hk.owner, pwd.getpwnam, "pw_uid")
        gid = _resolve_id(hk.group, grp.getgrnam, "gr_gid")
        os.chown(path, uid, gid)
    except (KeyError, OSError) as exc:
        warnings.append(f"chown {path} to {hk.owner}:{hk.group} failed: {exc}")
    return warnings


def housekeeping(output: Path, keep_days: int, now: datetime) -> list[Path]:
    """Delete dated files older than keep_days, except targets of *-latest* links."""
    output = Path(output)
    cutoff = now.timestamp() - keep_days * 86400
    protected = {p.resolve() for p in output.rglob("*-latest*") if p.is_symlink()}
    deleted: list[Path] = []
    for pattern in DATED_PATTERNS:
        for path in sorted(output.glob(pattern)):
            if path.is_symlink() or not path.is_file() or path.resolve() in protected:
                continue
            if path.stat().st_mtime < cutoff:
                path.unlink()
                deleted.append(path)
    return deleted
```

```python
"""ndp parse: scan XML + prefixes -> devices-<date>.json."""

from __future__ import annotations

import json
from dataclasses import asdict
from datetime import datetime
from pathlib import Path

from ndp.config import Config
from ndp.files import apply_perms, write_text_atomic
from ndp.inputs import InputError, load_prefixes
from ndp.inventory import build_inventory
from ndp.nmapxml import NmapXmlError, parse_scan
from ndp.result import StepResult


def run_parse(cfg: Config, now: datetime, xml_path: Path | None = None) -> StepResult:
    result = StepResult("parse")
    xml = Path(xml_path) if xml_path else cfg.scans_dir / "scan-latest.xml"
    try:
        report = parse_scan(xml)
        prefix_input = load_prefixes(cfg.paths.inputs / "prefixes.json")
    except (NmapXmlError, InputError) as exc:
        result.error = str(exc)
        return result

    result.warnings.extend(prefix_input.warnings)
    for role in sorted({p.role for p in prefix_input.prefixes} - set(cfg.nautobot.prefix_roles)):
        result.warnings.append(
            f"prefix role {role} is not in nautobot.prefix_roles: no function, lowest mgmt preference"
        )

    inventory = build_inventory(report.hosts, prefix_input.prefixes, cfg.nautobot.prefix_roles)
    result.warnings.extend(inventory.warnings)
    result.counts = {"hosts_up": report.summary.hosts_up, "devices": len(inventory.devices)}
    if not inventory.devices:
        result.error = f"no devices found in {xml}: not writing an empty inventory"
        return result

    out = cfg.paths.output / f"devices-{now:%Y%m%d}.json"
    doc = {
        "generated_at": now.isoformat(timespec="seconds"),
        "scan": asdict(report.summary),
        "warnings": list(result.warnings),
        "devices": [device.to_dict() for device in inventory.devices],
    }
    write_text_atomic(out, json.dumps(doc, indent=2) + "\n")
    result.warnings.extend(apply_perms(out, cfg.housekeeping))
    result.outputs["devices"] = str(out)
    return result
```

```python
        "-iL", str(targets_file),
    ]
    if exclude_file is not None:
        cmd += ["--excludefile", str(exclude_file)]
    cmd += ["-oX", f"{out_base}.xml", "-oG", f"{out_base}.txt"]
    return cmd


def run_scan(cfg: Config, now: datetime, env: Mapping[str, str] | None = None, runner=subprocess.run) -> StepResult:
    result = StepResult("scan")
    try:
        prefix_input = load_prefixes(cfg.paths.inputs / "prefixes.json")
        communities = communities_from_env(env)
    except (InputError, ConfigError) as exc:
        result.error = str(exc)
        return result
    result.warnings.extend(prefix_input.warnings)
    if not prefix_input.prefixes:
        result.error = "no IPv4 prefixes to scan in prefixes.json"
        return result

    exclude: Path | None = cfg.paths.inputs / "exclude.txt"
    if not exclude.exists():
        result.warnings.append(f"no exclude list at {exclude}: scanning without exclusions")
        exclude = None

    cfg.scans_dir.mkdir(parents=True, exist_ok=True)
    base = cfg.scans_dir / f"scan-{now:%Y%m%dT%H%M%S}"
    with tempfile.TemporaryDirectory(prefix="ndp-") as tmp:
        communities_file = Path(tmp) / "communities.txt"
        fd = os.open(communities_file, os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600)
        with os.fdopen(fd, "w") as fh:
            fh.write("\n".join(communities) + "\n")
        targets_file = Path(tmp) / "targets.txt"
        targets_file.write_text("\n".join(str(p.network) for p in prefix_input.prefixes) + "\n")
        cmd = build_nmap_command(cfg.scanner, targets_file, communities_file, base, exclude)
        log.info("running: %s", " ".join(cmd))
        try:
            proc = runner(cmd, stdout=subprocess.DEVNULL, stderr=subprocess.PIPE, text=True)
        except OSError as exc:
            result.error = f"cannot run nmap ({cfg.scanner.nmap_path}): {exc}"
            return result

    if proc.returncode != 0:
        result.error = f"nmap exited with {proc.returncode}: {(proc.stderr or '').strip()[-500:]}"
        return result
    xml = Path(f"{base}.xml")
    try:
        report = parse_scan(xml)
    except NmapXmlError as exc:
        result.error = str(exc)
        return result

    for suffix in ("xml", "txt"):
        path = Path(f"{base}.{suffix}")
        if path.exists():
            result.warnings.extend(apply_perms(path, cfg.housekeeping))
            atomic_symlink(path.name, cfg.scans_dir / f"scan-latest.{suffix}")
    result.outputs = {"scan_xml": str(xml), "scan_grep": f"{base}.txt"}
    result.counts = {
        "prefixes": len(prefix_input.prefixes),
        "hosts_up": report.summary.hosts_up,
        "hosts_total": report.summary.hosts_total,
    }
    return result
```

```python
"""CSV outputs: legacy device CSV, run summary CSV, services CSV."""

from __future__ import annotations

import csv
import io
from pathlib import Path

from ndp.files import write_text_atomic

LEGACY_COLUMNS = [
    "_key", "_updates", "hostname", "status", "telnet", "ssh", "snmp", "bgp", "enterprise",
    "os_slug", "function", "mgmt_ip", "mgmt_safe", "sysObjectId", "sysContact", "sysLocation",
    "sysUpTime", "physSerial", "physSoftware", "physDescription", "physName", "physModel",
    "ip", "communities",
]
SUMMARY_COLUMNS = [
    "id", "started", "started_str", "endtime", "endtime_str", "elapsed",
    "hosts_total", "hosts_up", "hosts_down", "filename",
]
SERVICES_COLUMNS = ["service", "hostname", "mgmt_ip", "interface", "ifAlias", "address"]

_LEGACY_SNMP = [
    "sysObjectId", "sysContact", "sysLocation", "sysUpTime", "physSerial",
    "physSoftware", "physDescription", "physName", "physModel",
]


def clean_text(value) -> str:
    """Legacy CSV cleanup: newlines -> '. ', ',' and '|' -> '_', stripped."""
    return str(value).replace("\n", ". ").replace(",", "_").replace("|", "_").strip()


def legacy_row(device: dict, include_communities: bool = True) -> dict[str, str]:
    snmp = device.get("snmp", {})
    ports = device.get("ports", {})
    row = {
        "_key": device["key"],
        "_updates": device.get("updates", 0),
        "hostname": device.get("hostname", ""),
        "status": device.get("status", ""),
        **{name: ports.get(name, "") for name in ("telnet", "ssh", "snmp", "bgp")},
        "enterprise": snmp.get("enterprise", ""),
        "os_slug": device.get("os_slug", ""),
        "function": device.get("function", ""),
        "mgmt_ip": device.get("mgmt_ip", ""),
        "mgmt_safe": device.get("mgmt_safe", 0),
        **{name: snmp.get(name, "") for name in _LEGACY_SNMP},
    }
    cleaned = {key: clean_text(value) for key, value in row.items()}
    cleaned["ip"] = "|".join(device.get("ips", []))
    cleaned["communities"] = "|".join(device.get("communities", [])) if include_communities else ""
    return cleaned


def _csv_text(columns: list[str], rows: list[dict]) -> str:
    buffer = io.StringIO()
    writer = csv.DictWriter(buffer, fieldnames=columns, extrasaction="ignore")
    writer.writeheader()
    writer.writerows(rows)
    return buffer.getvalue()


def write_legacy_csv(path: Path, devices: list[dict], include_communities: bool) -> None:
    rows = [legacy_row(device, include_communities) for device in devices]
    write_text_atomic(path, _csv_text(LEGACY_COLUMNS, rows))


def append_summary_csv(path: Path, scan: dict) -> None:
    path = Path(path)
    new_file = not path.exists() or path.stat().st_size == 0
    row = {"id": 1, **{name: scan.get(name, "") for name in SUMMARY_COLUMNS[1:]}}
    with open(path, "a", newline="") as fh:
        writer = csv.DictWriter(fh, fieldnames=SUMMARY_COLUMNS, lineterminator="\n")
        if new_file:
            writer.writeheader()
        writer.writerow(row)


def services_rows(devices: list[dict]) -> list[dict[str, str]]:
    rows = []
    for device in devices:
        for interface in device.get("interfaces", []):
            for service in interface.get("services", []):
                for address in interface.get("addresses") or [""]:
                    rows.append({
                        "service": service,
                        "hostname": device.get("hostname") or device["key"],
                        "mgmt_ip": device.get("mgmt_ip", ""),
                        "interface": interface.get("name", ""),
                        "ifAlias": interface.get("ifAlias", ""),
                        "address": address,
                    })
    return rows


def write_services_csv(path: Path, devices: list[dict]) -> int:
    rows = services_rows(devices)
    write_text_atomic(path, _csv_text(SERVICES_COLUMNS, rows))
    return len(rows)
```

Note: the legacy device CSV keeps `csv`'s default `\r\n` line ending (as the legacy parser wrote it); the summary CSV uses `\n` explicitly, so appended rows stay consistent with what the test asserts.

```python
"""Run manifest (for machines) and the output folder README (for people)."""

from __future__ import annotations

import os
from datetime import datetime
from pathlib import Path

from ndp import __version__

STEP_ORDER = ("exclude", "scan", "parse", "publish")
REPO_URL = "https://github.com/mwallraf/network-discovery-pipeline"

DESCRIPTIONS = {
    "scan_xml": "Raw nmap XML report of the full discovery",
    "scan_grep": "nmap grepable output of the full discovery",
    "devices": "All devices with SNMP details, interfaces and service IDs (JSON)",
    "devices_latest": "Link to the newest devices JSON",
    "legacy_csv": "One row per device, legacy column format",
    "summary_csv": "One row per scan run",
    "services_csv": "One row per service ID found in interface descriptions",
    "manifest": "Machine-readable record of this run",
    "readme": "This file",
}


def build_manifest(now: datetime, config_path: Path, results: dict[str, dict], sources: dict[str, dict]) -> dict:
    steps: dict[str, dict] = {}
    outputs: list[dict] = []
    warnings: list[str] = []
    for step in STEP_ORDER:
        result = results.get(step)
        if result is None:
            continue
        steps[step] = {key: result.get(key) for key in ("status", "started", "finished", "error", "counts")}
        for name, path in result.get("outputs", {}).items():
            outputs.append({"name": name, "path": path, "step": step, "rows": result.get("counts", {}).get(name)})
        warnings.extend(f"{step}: {warning}" for warning in result.get("warnings", []))
    return {
        "run_at": now.isoformat(timespec="seconds"),
        "versions": {
            "ndp": __version__,
            "scanner_image": os.environ.get("NDP_SCANNER_IMAGE", ""),
            "config_commit": os.environ.get("NDP_CONFIG_COMMIT", ""),
        },
        "config": str(config_path),
        "sources": sources,
        "steps": steps,
        "outputs": outputs,
        "warnings": warnings,
    }


def _rel(path: str, output_dir: Path) -> str:
    try:
        return str(Path(path).relative_to(output_dir))
    except ValueError:
        return path


def render_readme(manifest: dict, output_dir: Path) -> str:
    v = manifest["versions"]
    lines = [
        "# Network discovery output",
        "",
        f"Generated by [network-discovery-pipeline]({REPO_URL}) on {manifest['run_at']}.",
        "This file is rewritten on every run; do not edit it.",
        "",
        "## Where the data comes from",
        "",
        "| Source | System | URL | Query | Fetched at | Items |",
        "|---|---|---|---|---|---|",
    ]
    for name, src in manifest["sources"].items():
        lines.append(
            f"| {name} | {src.get('system', '')} | {src.get('url', '')} | {src.get('query', '')} "
            f"| {src.get('fetched_at', '')} | {src.get('items', '')} |"
        )
    lines += ["", "## Steps of the last run", "", "| Step | Status | Started | Finished |", "|---|---|---|---|"]
    for step, info in manifest["steps"].items():
        lines.append(f"| ndp {step} | {info.get('status')} | {info.get('started')} | {info.get('finished')} |")
    lines += ["", "## Files", "", "| File | Produced by | Content |", "|---|---|---|"]
    for output in manifest["outputs"]:
        lines.append(
            f"| `{_rel(output['path'], output_dir)}` | ndp {output['step']} | {DESCRIPTIONS.get(output['name'], '')} |"
        )
```

```python
"""ndp publish: devices JSON -> CSV/JSON outputs, run manifest, README, housekeeping."""

from __future__ import annotations

import json
from datetime import datetime
from pathlib import Path

from ndp.config import Config
from ndp.files import apply_perms, atomic_symlink, housekeeping, write_text_atomic
from ndp.inputs import InputError, load_prefixes
from ndp.manifest import build_manifest, render_readme
from ndp.result import StepResult, now_local
from ndp.state import load_step_results
from ndp.writers import append_summary_csv, write_legacy_csv, write_services_csv


def _devices_file(cfg: Config) -> Path | None:
    parse = load_step_results(cfg.state_dir).get("parse")
    if not parse or parse.get("status") == "failed":
        return None
    path = parse.get("outputs", {}).get("devices")
    return Path(path) if path and Path(path).exists() else None


def _sources(cfg: Config) -> dict[str, dict]:
    try:
        prefixes = load_prefixes(cfg.paths.inputs / "prefixes.json")
    except InputError:
        return {}
    return {"prefixes": {**prefixes.source, "items": len(prefixes.prefixes)}}


def run_publish(cfg: Config, now: datetime, config_path: Path) -> StepResult:
    result = StepResult("publish")
    devices_path = _devices_file(cfg)
    if devices_path is None:
        result.error = "no successful parse result found; run 'ndp parse' first"
        return result
    doc = json.loads(devices_path.read_text())
    devices = doc.get("devices", [])
    out = cfg.paths.output
    date = f"{now:%Y%m%d}"
    written: list[Path] = []

    if cfg.outputs.devices_json:
        link = out / "devices-latest.json"
        atomic_symlink(devices_path.name, link)
        result.outputs["devices_latest"] = str(link)
    if cfg.outputs.legacy_csv:
        csv_path = out / f"discovery.csv.{date}"
        write_legacy_csv(csv_path, devices, cfg.outputs.legacy_csv_communities)
        atomic_symlink(csv_path.name, out / "discovery-latest.csv")
        summary = out / "discovery-summary.csv"
        append_summary_csv(summary, doc.get("scan", {}))
        written += [csv_path, summary]
        result.outputs.update(legacy_csv=str(csv_path), summary_csv=str(summary))
        result.counts["legacy_csv"] = len(devices)
    if cfg.outputs.services_csv:
        services = out / f"services-{date}.csv"
        result.counts["services_csv"] = write_services_csv(services, devices)
        atomic_symlink(services.name, out / "services-latest.csv")
        written.append(services)
        result.outputs["services_csv"] = str(services)
    for path in written:
        result.warnings.extend(apply_perms(path, cfg.housekeeping))

    result.counts = {"devices": len(devices), **result.counts}
    result.counts["deleted_files"] = len(housekeeping(out, cfg.housekeeping.keep_days, now))

    manifest_path = out / f"run-{now:%Y%m%dT%H%M%S}.json"
    readme_path = out / "README.md"
    result.outputs.update(manifest=str(manifest_path), readme=str(readme_path))
    result.started = now.isoformat(timespec="seconds")
    result.finished = now_local().isoformat(timespec="seconds")
    results = {**load_step_results(cfg.state_dir), "publish": result.to_dict()}
    manifest = build_manifest(now, config_path, results, _sources(cfg))
    write_text_atomic(manifest_path, json.dumps(manifest, indent=2) + "\n")
    write_text_atomic(readme_path, render_readme(manifest, out))
    for path in (manifest_path, readme_path):
        result.warnings.extend(apply_perms(path, cfg.housekeeping))
    return result
```

```python
"""ndp run: scan -> parse -> publish, for use without n8n (cron, by hand)."""

from __future__ import annotations

import subprocess
from collections.abc import Mapping
from datetime import datetime
from pathlib import Path

from ndp.config import Config
from ndp.result import StepResult, now_local
from ndp.state import save_step_result
from ndp.step_parse import run_parse
from ndp.step_publish import run_publish
from ndp.step_scan import run_scan


def run_all(
    cfg: Config,
    now: datetime,
    config_path: Path,
    env: Mapping[str, str] | None = None,
    runner=subprocess.run,
) -> StepResult:
    result = StepResult("run")
    steps = [
        ("scan", lambda t: run_scan(cfg, t, env=env, runner=runner)),
        ("parse", lambda t: run_parse(cfg, t)),
        ("publish", lambda t: run_publish(cfg, t, config_path)),
    ]
    for name, fn in steps:
        started = now_local()
        step_result = fn(started)
        step_result.started = started.isoformat(timespec="seconds")
        step_result.finished = now_local().isoformat(timespec="seconds")
        save_step_result(cfg.state_dir, step_result)
        result.warnings.extend(f"{name}: {warning}" for warning in step_result.warnings)
        result.outputs.update({f"{name}.{key}": value for key, value in step_result.outputs.items()})
        result.counts.update({f"{name}.{key}": value for key, value in step_result.counts.items()})
        if step_result.error:
            result.error = f"{name}: {step_result.error}"
            break
    return result
```

```python
"""Compare a legacy discovery CSV with a new one, row by _key.

Usage: python -m ndp.compare OLD.csv NEW.csv
"""

from __future__ import annotations

import csv
import sys
from pathlib import Path


def _rows(path: Path) -> dict[str, dict[str, str]]:
    with open(path, newline="") as fh:
        return {row["_key"]: row for row in csv.DictReader(fh)}


def compare_csv(old: Path, new: Path) -> dict:
    old_rows, new_rows = _rows(old), _rows(new)
    column_diffs: dict[str, int] = {}
    examples: dict[str, list[tuple[str, str, str]]] = {}
    for key in sorted(old_rows.keys() & new_rows.keys()):
        for column, old_value in old_rows[key].items():
            new_value = new_rows[key].get(column, "")
            if old_value != new_value:
                column_diffs[column] = column_diffs.get(column, 0) + 1
                if len(examples.setdefault(column, [])) < 5:
                    examples[column].append((key, old_value, new_value))
    return {
        "only_old": sorted(old_rows.keys() - new_rows.keys()),
        "only_new": sorted(new_rows.keys() - old_rows.keys()),
        "column_diffs": column_diffs,
        "examples": examples,
    }


def main(argv: list[str] | None = None) -> int:
    old, new = (Path(arg) for arg in (argv if argv is not None else sys.argv[1:]))
    report = compare_csv(old, new)
    print(f"devices only in {old.name}: {len(report['only_old'])}")
    for key in report["only_old"][:20]:
        print(f"  {key}")
    print(f"devices only in {new.name}: {len(report['only_new'])}")
    for key in report["only_new"][:20]:
        print(f"  {key}")
    for column, count in sorted(report["column_diffs"].items()):
        print(f"{column}: {count} rows differ")
        for key, old_value, new_value in report["examples"][column]:
            print(f"  {key}: {old_value!r} -> {new_value!r}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

````markdown
# network-discovery-pipeline

Daily network discovery: find every device in a set of prefixes, read its
identity over SNMP and publish an inventory as JSON and CSV.

`ndp` runs the [nmap-network-discovery](https://github.com/mwallraf/nmap-network-discovery)
scanner, merges hosts that are the same device, picks one management IP per
device based on prefix roles, and writes outputs that other scripts can use.
Scheduling (n8n, cron) and site configuration live elsewhere: this repository
holds only the tool and generic examples.

## Data flow

| Source | Fetched by | Step | Output | Location |
|---|---|---|---|---|
| Prefixes with a discovery role (Nautobot) | n8n, before the run | `ndp scan` | `scan-<ts>.xml`, `scan-latest.xml` | `<output>/nmap/` |
| Exclude list (`exclude.txt`, plan 2: `ndp exclude`) | n8n / `ndp exclude` | `ndp scan` | (input only) | `<inputs>/` |
| Scan XML + prefixes | | `ndp parse` | `devices-<date>.json` | `<output>/` |
| Devices JSON | | `ndp publish` | `devices-latest.json`, `discovery.csv.<date>`, `discovery-latest.csv`, `discovery-summary.csv`, `services-latest.csv`, `run-<ts>.json`, `README.md` | `<output>/` |

Every run writes `run-<ts>.json` (sources, steps, versions, warnings, files)
and regenerates `README.md` in the output folder, so the output explains
itself.

## Inputs

`<inputs>/prefixes.json`, normally written by n8n from Nautobot:

```json
{
  "source": {"system": "nautobot", "url": "https://nautobot.example/", "query": "...", "fetched_at": "..."},
  "prefixes": [{"prefix": "192.0.2.0/24", "role": "INFRA_LOOPBACK"}]
}
```

`<inputs>/exclude.txt` (optional): one IP per line, not scanned.

SNMP communities: environment variable `SNMP_COMMUNITIES` (comma-separated),
for example from a `.env` file with mode 0600. Never pass them as arguments.

## Configuration

See [`examples/ndp.example.yaml`](examples/ndp.example.yaml). The order of
`nautobot.prefix_roles` is the preference when a device has IPs in several
roles; the device's function comes from the role of its management IP.

## Running

```bash
docker run --rm --env-file .env \
  -v /path/ndp.yaml:/etc/ndp/ndp.yaml:ro \
  -v /data/network-discovery:/data/network-discovery \
  ghcr.io/mwallraf/network-discovery-pipeline:latest run
```

Steps: `ndp config`, `ndp scan`, `ndp parse [--xml FILE]`, `ndp publish`,
`ndp run`. Each prints a JSON summary on stdout; exit code `0` = ok, `2` = ok
with warnings, `1` = failed. A failed step never replaces a `*-latest` file.

Compare with a legacy CSV: `python -m ndp.compare old.csv new.csv`.
````
