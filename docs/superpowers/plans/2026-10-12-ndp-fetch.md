# ndp fetch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the whole pipeline run without n8n: a new step `ndp fetch` queries Nautobot and writes `inputs/infra-routers.json` and `inputs/prefixes.json`, and `ndp run --fetch` runs fetch → exclude → scan → parse → publish.

**Architecture:** A small standard-library GraphQL client (`ndp.nautobot`, urllib, no new dependency) runs the same two queries as the n8n workflow. Nautobot uses a locally signed certificate, so certificate checking can be switched off (`nautobot.verify_tls: false`, reported as a warning on every fetch). A proxy is set either explicitly (`nautobot.proxy`) or through the standard `HTTPS_PROXY`/`HTTP_PROXY`/`NO_PROXY` environment variables in `.env`. A new step module `ndp.step_fetch` builds the two input files in exactly the format n8n writes, checks them with the existing loaders, and only then replaces the old files. The Nautobot URL lives in `ndp.yaml`; the token comes from the environment (`NAUTOBOT_TOKEN`, server `.env`). n8n keeps its own fetch nodes; both paths write the same files and record who fetched them in `source.fetched_by`.

**Tech Stack:** Python 3.11+, pydantic 2, PyYAML, pytest, `urllib.request`, `http.server` (tests only); POSIX sh wrapper; n8n workflow generator (Python).

**Spec:** `docs/superpowers/specs/2026-10-09-network-discovery-pipeline-design.md` (sections 4, 5, 6, 12). Task 5 updates the spec for this step.

**Repos:** Tasks 1–5 in `network-discovery-pipeline/` (branch `feat/ndp-fetch` from `main`). Task 6 in `network-discovery-config/` (branch `feat/ndp-fetch` from `main`). Test commands:
- public: `cd network-discovery-pipeline && .venv/bin/pytest -q`
- private: `cd network-discovery-config && ../network-discovery-pipeline/.venv/bin/pytest -q`

## Global Constraints

- The public repo contains only documentation values: `192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`, invented names, `https://nautobot.example/`. Real site values only in `network-discovery-config`.
- Secrets come from the environment only, never from `ndp.yaml`, CLI arguments, logs, step results or the run manifest. `NAUTOBOT_TOKEN` must never appear in any output, error message or file ndp writes.
- Every step prints one JSON `StepResult`; exit codes 0 ok, 2 warnings, 1 failed.
- A failed step never replaces an existing file: if Nautobot fails or returns unusable data, the previous `inputs/*.json` stay as they are.
- File format = the input contract in spec section 6, identical to what the n8n *Shape* nodes write (`source.system/url/query/fetched_at`, `devices[]{name, role, mgmt_ip}`, `prefixes[]{prefix, role}`), plus `source.fetched_by`.
- Same GraphQL queries as `network-discovery-config/tools/build_workflows.py` (`DEVICE_QUERY`, `PREFIX_QUERY`), POSTed to `<url>/api/graphql/` with header `Authorization: Token <token>`.
- No new runtime dependencies (pyproject `dependencies` stays `pydantic`, `PyYAML`).
- Nothing is pushed. Commits stay local until the user says so.

## Review Focus

1. **Token leakage**: an HTTP error page, a GraphQL error or a crash must not put the token in the step result. Pinned by `test_token_never_in_result` (Task 3).
2. **Nautobot returns nothing for a role list** (typo in a role name): the step must fail and keep yesterday's files, not write an empty prefixes list that makes the scan scan nothing. Pinned by `test_empty_prefixes_fail_and_keep_old_files` (Task 3).
3. **Nautobot returns a bad address** (e.g. `mgmt_ip: "nope"`): the existing loaders reject it; nothing is written. Pinned by `test_invalid_data_keeps_old_files` (Task 3).
4. **Nautobot unreachable / TLS failure / timeout** in `ndp run --fetch`: the run continues with the previous inputs and says so. Pinned by `test_fetch_failure_does_not_stop_the_run` (Task 4).
5. **Files written as root by the container** must stay replaceable by the n8n SSH upload (service user, shared group): fetch applies the configured owner/group/mode like every other output. Pinned by `test_fetch_applies_permissions` (Task 3).
6. **Proxy in the environment but Nautobot is internal**: `NO_PROXY` must make the request go direct; an explicit `nautobot.proxy` must win over the environment. Pinned by `test_no_proxy_goes_direct` and `test_explicit_proxy_is_used` (Task 2).
7. **TLS checking switched off silently**: every fetch with `verify_tls: false` says so in its warnings, so the run README shows it. Pinned by `test_insecure_tls_is_a_warning` (Task 3).

class Handler(BaseHTTPRequestHandler):
    status = 200
    reply = b'{"data": {"devices": []}}'
    seen: list = []

    def do_POST(self):
        body = self.rfile.read(int(self.headers["Content-Length"]))
        Handler.seen.append((self.path, dict(self.headers), json.loads(body)))
        self.send_response(Handler.status)
        self.send_header("Content-Type", "application/json")

        self.wfile.write(Handler.reply)

```python
"""Minimal Nautobot GraphQL client for 'ndp fetch'. The token comes from the environment."""

from __future__ import annotations

import json
import os
import ssl
import urllib.error
import urllib.request
from collections.abc import Callable, Mapping

# the same queries as the n8n workflow (network-discovery-config/tools/build_workflows.py)
DEVICE_QUERY = "query ($roles: [String]) {\n  devices(role: $roles) {\n    name\n    role { name }\n    primary_ip4 { address }\n  }\n}"
PREFIX_QUERY = "query ($roles: [String]) {\n  prefixes(role: $roles) {\n    prefix\n    role { name }\n  }\n}"

Post = Callable[[str, bytes, dict[str, str]], bytes]


class NautobotError(Exception):
    """Nautobot could not be queried or gave an unusable answer."""


def token_from_env(env: Mapping[str, str] | None = None) -> str:
    env = os.environ if env is None else env
    token = env.get("NAUTOBOT_TOKEN", "").strip()
    if not token:
        raise NautobotError("NAUTOBOT_TOKEN is not set or empty")
    return token


def http_post(timeout: float, verify_tls: bool = True, proxy: str | None = None) -> Post:
    """A POST function using urllib.

    verify_tls=False accepts any certificate (locally signed Nautobot).
    proxy=None uses HTTPS_PROXY/HTTP_PROXY/NO_PROXY from the environment.
    """
    context = ssl.create_default_context()
    if not verify_tls:
        context.check_hostname = False
        context.verify_mode = ssl.CERT_NONE
    proxies = {"http": proxy, "https": proxy} if proxy else None  # None = environment
    opener = urllib.request.build_opener(
        urllib.request.ProxyHandler(proxies),
        urllib.request.HTTPSHandler(context=context),
    )

    def post(url: str, body: bytes, headers: dict[str, str]) -> bytes:
        request = urllib.request.Request(url, data=body, headers=headers, method="POST")
        try:
            with opener.open(request, timeout=timeout) as response:
                return response.read()
        except urllib.error.HTTPError as exc:
            detail = exc.read(300).decode("utf-8", "replace").strip()
            raise NautobotError(f"Nautobot returned HTTP {exc.code} for {url}: {detail}") from None
        except (urllib.error.URLError, OSError) as exc:  # DNS, refused, proxy, TLS, timeout
            raise NautobotError(f"cannot reach Nautobot at {url}: {getattr(exc, 'reason', exc)}") from None

    return post


def graphql(url: str, token: str, query: str, variables: dict, post: Post) -> dict:
    endpoint = url.rstrip("/") + "/api/graphql/"
    body = json.dumps({"query": query, "variables": variables}).encode()
    headers = {
        "Authorization": f"Token {token}",
        "Content-Type": "application/json",
        "Accept": "application/json",
    }
    raw = post(endpoint, body, headers)
    try:
        doc = json.loads(raw)
    except ValueError:
        raise NautobotError(f"Nautobot returned no JSON from {endpoint}: {raw[:200]!r}") from None
    if not isinstance(doc, dict):
        raise NautobotError(f"Nautobot returned no JSON object from {endpoint}")
    if doc.get("errors"):
        raise NautobotError("Nautobot GraphQL: " + json.dumps(doc["errors"])[:500])
    data = doc.get("data")
    if not isinstance(data, dict):
        raise NautobotError(f"Nautobot GraphQL returned no data from {endpoint}")
    return data
```

Rules:
- `nautobot.url` missing → failed, message names `nautobot.url`.
- Empty `device_roles` → skip `infra-routers.json` with a warning (an empty role filter could return every device).
- Zero devices or zero prefixes returned → failed (same rule as the n8n *Shape* nodes).
- `verify_tls: false` → warning on every fetch (so the run README shows it).
- Both files are built and checked with the loaders in a temp folder first; only if both load, they replace the files in `inputs/`. Loader warnings become step warnings.

```python
"""ndp fetch: Nautobot -> inputs/infra-routers.json and inputs/prefixes.json.

The same files n8n writes, so the pipeline also runs without n8n (cron, by hand).
"""

from __future__ import annotations

import json
import tempfile
from collections.abc import Mapping
from datetime import datetime
from pathlib import Path

from ndp.config import Config
from ndp.files import apply_perms, write_text_atomic
from ndp.inputs import InputError, load_infra_routers, load_prefixes
from ndp.nautobot import DEVICE_QUERY, PREFIX_QUERY, NautobotError, Post, graphql, http_post, token_from_env
from ndp.result import StepResult


def _name(value) -> str:
    return str(value.get("name") or "") if isinstance(value, dict) else ""


def _devices(data: dict) -> list[dict]:
    return [
        {"name": d.get("name"), "role": _name(d.get("role")),
         "mgmt_ip": (d.get("primary_ip4") or {}).get("address")}
        for d in data.get("devices") or [] if isinstance(d, dict)
    ]


def _prefixes(data: dict) -> list[dict]:
    return [
        {"prefix": p.get("prefix"), "role": _name(p.get("role"))}
        for p in data.get("prefixes") or [] if isinstance(p, dict)
    ]


def _document(url: str, key: str, roles: list[str], items: list[dict], now: datetime) -> str:
    source = {
        "system": "nautobot",
        "url": url,
        "query": f"{key} with role in [{', '.join(roles)}]",
        "fetched_at": now.isoformat(timespec="seconds"),
        "fetched_by": "ndp fetch",
    }
    return json.dumps({"source": source, key: items}, indent=2) + "\n"


def run_fetch(cfg: Config, now: datetime, env: Mapping[str, str] | None = None, post: Post | None = None) -> StepResult:
    result = StepResult("fetch")
    nb = cfg.nautobot
    if not nb.url:
        result.error = "nautobot.url is not set in ndp.yaml"
        return result
    if not nb.verify_tls:
        result.warnings.append("TLS certificate of Nautobot not checked (nautobot.verify_tls: false)")
    device_roles = list(nb.device_roles)
    prefix_roles = list(nb.prefix_roles)
    files: dict[str, str] = {}  # output name -> file text
    try:
        token = token_from_env(env)
        post = post or http_post(nb.timeout_s, nb.verify_tls, nb.proxy)
        if device_roles:
            devices = _devices(graphql(nb.url, token, DEVICE_QUERY, {"roles": device_roles}, post))
            if not devices:
                raise NautobotError(f"Nautobot returned no devices for roles {', '.join(device_roles)}")
            files["infra_routers"] = _document(nb.url, "devices", device_roles, devices, now)
        else:
            result.warnings.append("nautobot.device_roles is empty; infra-routers.json not fetched")
        prefixes = _prefixes(graphql(nb.url, token, PREFIX_QUERY, {"roles": prefix_roles}, post))
        if not prefixes:
            raise NautobotError(f"Nautobot returned no prefixes for roles {', '.join(prefix_roles)}")
        files["prefixes"] = _document(nb.url, "prefixes", prefix_roles, prefixes, now)
    except NautobotError as exc:
        result.error = str(exc)
        return result

    names = {"infra_routers": "infra-routers.json", "prefixes": "prefixes.json"}
    loaders = {"infra_routers": load_infra_routers, "prefixes": load_prefixes}
    # check both files with the loaders the other steps use before replacing anything
    with tempfile.TemporaryDirectory(prefix="ndp-fetch-") as tmp:
        for key, text in files.items():
            path = Path(tmp) / names[key]
            path.write_text(text)
            try:
                loaded = loaders[key](path)
            except InputError as exc:
                result.error = f"Nautobot data is not valid: {exc}"
                return result
            result.counts[key] = len(loaded.routers if key == "infra_routers" else loaded.prefixes)
            result.warnings.extend(f"{key}: {warning}" for warning in loaded.warnings)
    for key, text in files.items():
        target = cfg.paths.inputs / names[key]
        write_text_atomic(target, text)
        result.warnings.extend(apply_perms(target, cfg.housekeeping))
        result.outputs[key] = str(target)
    return result
```
